Try it

  1. Open this page with the App Clip (your Aura tag or link): the phone appears above and in devices_appcliped/.
  2. On a computer, open aurakit-admin.php and set this phone to off.
  3. Launch the App Clip again: the phone lands on blocked.html.
  4. Set it back to on: it sees this page again.

Files on the server

your-site/demo/
├── index.html            this page: checkDevice(), then registerDevice()
├── blocked.html          page for phones set to off
├── aurakit.js            copied from the root of AuraKit
├── aurakit-devices.php   records the phones, answers their status
├── aurakit-admin.php     on/off list (password in ADMIN_PASSWORD)
└── devices_appcliped/    created by itself on the first launch
    ├── .htaccess         keeps the folder private
    ├── index.html
    └── 3f1c….json        one file per phone, "status": "on" | "off"
